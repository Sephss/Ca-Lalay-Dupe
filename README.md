# CA-LALAY — Vehicle Service Management System

An Android-based vehicle service management system with 2D mapping, designed to connect customers with vehicle service providers and simplify service discovery, booking, and transaction management.

## Features

- **User Management** — Customer and service provider registration and account management.
- **2D Mapping** — Locate nearby vehicle service providers and view estimated distances.
- **Service Management** — Create, browse, search, and filter vehicle services.
- **Booking & Billing** — Schedule and reschedule services, manage bookings, and view billing information.
- **Messaging** — Direct messaging between customers and service providers with photo sharing.
- **Transactions & Reports** — View transaction history and generate service reports.
- **Ratings & Feedback** — Submit reviews and feedback for completed services.
- **Admin Dashboard** — Manage accounts, approve service providers, and monitor administrative activities.

## Tech Stack

- **Mobile:** Java, Android Studio
- **Backend:** Firebase Authentication, Firebase Realtime Database
- **Mapping:** 2D Mapping Integration
- **Version Control:** GitHub
- **Libraries:** Third-party Android libraries
